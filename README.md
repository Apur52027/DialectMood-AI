# 🌿 DialectMood AI

Bangla Dialect Intelligence & Emotional Support Platform.

## Features

- Email and Password Authentication
- Dinajpur Dialect Identification
- Rangpur Dialect Identification
- Standard Bangla Identification
- Bangla Sentiment Analysis
- Sentiment Explanation
- Linguistic Clue Extraction
- AI Mood Companion
- Personal Analysis Journal
- Sentiment Distribution Chart

## Technology Stack

- Python
- Streamlit
- LangChain
- Groq API
- GPT-OSS 120B
- SQLite
- Plotly
- Pandas

## Installation

Clone the repository:

git clone https://github.com/USERNAME/DialectMoodAI.git

Enter the directory:

cd DialectMoodAI

Create virtual environment:

python -m venv venv

Activate:

venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Create .env file and add your Groq API key.

Run:

streamlit run app.py

## Deployment

Deploy using Streamlit Community Cloud.

Configure GROQ_API_KEY and GROQ_MODEL
in Streamlit Secrets.
